오늘의 채용 인사이트

점핏은 금융·피지컬 AI로 바뀌었고, 잡코리아는 어제 보이던 네 곳이 빠졌다

어제 점핏 통과분이던 제네시스네스트 Java 백엔드(용인), 베스텔라랩 백엔드·인프라 풀스택(안양), 아이엔마케팅 웹 2건(파주), 블루개러지 풀스택·LLM 2건(강동), 디지털포토 클라우드(서초), 인아텍앤코포 자율주행(인천)은 최근 등록 3페이지에서 내려갔다. 그 자리에 영등포 콴텍 IRP 풀스택(최소 3년, Java·Spring Boot·React), 강남 에너자이 ML(최소 1년), 러닝포인트 머신러닝 신입, 서초 지엔에이컴퍼니 Data Scientist(최소 2년), 성남 엔티엘헬스케어 MLOps(최소 1년), 강남 씨메스 Backend·Physical AI 2건, 서초 스콥정보통신 시스템 개발(최소 3년), 쓰리아이 컴퓨터비전 인턴이 들어왔다. 잡코리아에서는 ㈜에스이파트너즈·서큘러스·㈜팜소프트·㈜제타럭스 시스템이 검색에서 빠지고, 유한회사 넥스트씨아이코리아 주니어 백엔드(과천), ㈜플레이웍스 프론트(강남), ㈜약진통상 IT(송파), ㈜세인티 로봇 SW(남양주), 슈어소프트테크㈜ 신입 공채(성남)가 신규다. 스타트업 웹은 키키코드㈜·디지타이드㈜·㈜데일리페이·㈜플레이웍스, SI는 ㈜파워인포텍·㈜지에프씨코리아·㈜위세아이텍, 금융IT는 콴텍 1건, 결제 인접은 ㈜데일리페이 2건이다.

백엔드 Java/Spring은 여섯 건으로 줄었고, Node는 다섯 건을 유지했다

백엔드 16건은 어제와 같다. Java/Spring은 어제 8건에서 6건(㈜마이스, 로동, 키키코드㈜, 디자인 펀치, ㈜엠엑스엔코리아, ㈜유니유니)으로 줄었고, 어제 Java칸이던 제네시스네스트·㈜에스이파트너즈는 빠졌다. Node.js는 어제와 같은 5건(키키코드㈜, ㈜엠엑스엔코리아, 노빌더, 티엔에이치㈜, ㈜리비바이오)이고 둘 다 적힌 공고는 2건(키키코드㈜, ㈜엠엑스엔코리아)으로 변하지 않았다. 차트 상위는 Java·Python 16회, React 15회, MySQL 14회, Git 12회다.

AI 전담은 열세 건으로 늘었고, 웹에 AI를 붙인 자리는 여섯 건이다

AI·머신러닝 섹션은 어제 10건에서 13건이다. 점핏 인아텍앤코포·블루개러지 LLM이 내려가고 에너자이·러닝포인트·지엔에이컴퍼니·엔티엘헬스케어·씨메스 Physical AI·쓰리아이 비전이 들어왔으며, 잡코리아는 서큘러스·㈜팜소프트가 빠지고 ㈜세인티 로봇 SW가 전담으로 붙었다. 웹 제목이나 직무에 AI가 붙은 부착형은 어제 5건에서 6건이다. ㈜세인티·㈜플레이웍스 프론트, ㈜파라미타에이아이·㈜인포플라·㈜엘세븐시큐리티·㈜아크릴 풀스택이다.

신입 단독은 열 건을 유지했고, 경력 무관은 인텔렉투스 한 곳이다

경력 칸이 신입만 적힌 직무 공고는 어제와 같이 10건이다. ㈜마이스, 디지타이드㈜, 티엔에이치㈜, ㈜큐비틱, ㈜티맥스티베로, ㈜투모어스텝스, ㈜서로티엔에스, ㈜제논에 러닝포인트 머신러닝과 쓰리아이 비전 인턴이 들어왔고 아이엔마케팅 웹 신입과 서큘러스는 빠졌다. 제목에 경력 무관을 명시한 자리는 ㈜인텔렉투스 백엔드(강남)뿐이다. 최소 1년 이하를 받는 주니어 자리는 키키코드㈜·㈜리비바이오·㈜애드락애드버테인먼트·㈜너드소프트·㈜지에프씨코리아·에너자이·엔티엘헬스케어·씨메스 Physical AI다.

강남·서초·송파는 스물일곱 건으로 늘었고, 영등포에 콴텍이 붙었다

직무 공고 기준 강남·서초·송파는 어제 21건에서 27건이다. 점핏 디지털포토(서초)가 빠지고 씨메스 2건(강남)·에너자이(강남)·쓰리아이(강남)·지엔에이컴퍼니(서초)·스콥정보통신(서초)이 들어왔으며 잡코리아 ㈜플레이웍스(강남)·㈜약진통상(송파)이 더해졌다. 성남·판교는 6건(키키코드㈜·티엔에이치㈜·㈜유니유니·㈜티맥스티베로·㈜지엠디소프트·엔티엘헬스케어)으로 어제와 같고, 금천·구로는 서큘러스가 빠져 6건(로동 2건·디자인 펀치·에스티오(STO)·㈜파워인포텍·㈜지에프씨코리아)이다. 영등포는 ㈜데일리페이 2건에 콴텍이 더해져 3건이다.

오늘 마감이던 서큘러스는 빠졌고, 공채는 슈어소프트가 더해졌다

오늘(10-02) 마감이던 서큘러스 Physical AI는 검색에서 사라졌다. 대기업 공채는 어제 3건에서 4건이다. 한솔피엔에스(~10-11), 현대오토에버㈜(~10-12), ㈜이카운트(~10-14)가 유지되고 슈어소프트테크㈜ 2027 신입 공채(~10-20, 성남)가 신규다. 가장 임박한 직무는 ㈜큐비틱 프론트(~10-07)이고, 이어서 ㈜너드소프트(~10-08), ㈜엠엑스엔코리아·㈜유니유니·㈜제논(~10-10)이다.
