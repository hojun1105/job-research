오늘의 채용 인사이트

점핏은 웹·클라우드 쪽으로 한 바퀴 돌았고, 잡코리아는 어제 마감분과 공채가 빠졌다

어제 점핏 통과분이던 시스콘 웹 백엔드(성남, 최소 3년), 인젠트 iBiz Java(영등포), 메타넷디지털 M365·AI DevOps(종로), 반프 풀스택 전문연구요원(강남), 러닝포인트 풀스택 2건, 건솔루션 AI응용(안양), 에이스웍스코리아 자율주행(강남), 아론티어 AI 2건(서초)은 최근 등록 3페이지에서 내려갔다. 그 자리에 용인 제네시스네스트 Java 백엔드(최소 1년, Spring), 안양 베스텔라랩 백엔드·인프라 풀스택(최소 2년), 파주 아이엔마케팅 웹 신입·경력 2건, 강동 블루개러지 풀스택·LLM 2건(같은 회사 프론트·디자이너 공고는 상한으로 제외), 서초 디지털포토 클라우드(최소 3년), 인천 인아텍앤코포 자율주행로봇이 들어왔다. 잡코리아에서는 어제 마감된 ㈜트윔·㈜퍼펙토리·몽구스에이아이㈜·㈜날리지포인트와 CJ·㈜비아이매트릭스·테슬라코리아 공채가 빠지고, ㈜에스이파트너즈 웹시스템(중구), ㈜서로티엔에스 프론트·백엔드(고양), ㈜티맥스티베로 프론트(성남, 전문연구요원), 기적기획 프론트 재등록(~10-30)이 신규다. 스타트업 웹은 키키코드㈜·디지타이드㈜·아이엔마케팅·블루개러지·㈜데일리페이, SI는 ㈜파워인포텍·㈜지에프씨코리아·㈜위세아이텍·㈜에스이파트너즈, 결제 인접은 ㈜데일리페이 2건, 제조·로봇 인접은 인아텍앤코포다.

백엔드 Java/Spring은 여덟 건으로 줄었고, Node는 다섯 건을 유지했다

백엔드 16건(어제 18건)에서 Java/Spring은 8건이다. ㈜마이스, 로동, 키키코드㈜, 디자인 펀치, ㈜엠엑스엔코리아, ㈜유니유니에 제네시스네스트·㈜에스이파트너즈가 더해졌고, 어제 Java칸이던 시스콘·인젠트·㈜날리지포인트는 빠졌다. Node.js는 어제와 같은 5건(키키코드㈜, ㈜엠엑스엔코리아, 노빌더, 티엔에이치㈜, ㈜리비바이오)이다. 둘 다 적힌 공고는 2건(키키코드㈜, ㈜엠엑스엔코리아)으로 변하지 않았다. 차트 상위는 React 16회, Java 15회, MySQL 13회, Git·Python·JavaScript 12회다.

AI 전담은 열 건으로 늘었고, 웹에 AI를 붙인 자리는 다섯 건으로 줄었다

AI·머신러닝 섹션은 어제 5건에서 10건이다. 점핏 건솔루션·에이스웍스코리아·아론티어 2건이 내려가고 블루개러지 LLM(강동, 최소 3년, PyTorch)·인아텍앤코포 자율주행(인천, 최소 1년, OpenCV·ROS)이 들어왔으며, 잡코리아는 서큘러스에 더해 ㈜팜소프트 AI Agent(광명, 3년), ㈜지엠디소프트 포렌식 AI(성남), 이한크리에이티브㈜ VLM/LLM(과천), 레피나(Refinar)(용인), ㈜제논 GenOS 인턴(강남), 더케이엠에스㈜(마포), ㈜두아즈 인턴(강남)이 전담으로 붙었다. 웹 제목이나 직무에 AI가 붙은 부착형은 어제 8건에서 5건이다. ㈜세인티 프론트, ㈜파라미타에이아이·㈜인포플라·㈜엘세븐시큐리티·㈜아크릴 풀스택이고 메타넷디지털·반프·몽구스에이아이㈜는 목록에서 빠졌다.

신입 단독은 열 건으로 늘었고, 경력 무관은 인텔렉투스 한 곳이다

경력 칸이 신입만 적힌 직무 공고는 어제 8건에서 10건이다. ㈜마이스, 디지타이드㈜, 티엔에이치㈜, ㈜큐비틱, ㈜투모어스텝스, 서큘러스에 아이엔마케팅 웹 신입, ㈜서로티엔에스, ㈜티맥스티베로, ㈜제논이 들어왔고 러닝포인트 신입과 ㈜퍼펙토리는 빠졌다. 제목에 경력 무관을 명시한 자리는 ㈜인텔렉투스 백엔드(강남)뿐이다. 최소 1년 이하를 받는 주니어 자리는 제네시스네스트·㈜리비바이오·키키코드㈜·㈜애드락애드버테인먼트·㈜너드소프트·㈜지에프씨코리아·아이엔마케팅 경력·인아텍앤코포다.

강남·서초·송파는 스물한 건을 유지했고, 강동·파주가 새 묶음이다

직무 공고 기준 강남·서초·송파는 어제와 같이 21건이다. 점핏 반프(강남)·아론티어 2건(서초)·에이스웍스코리아(강남)가 빠지고 디지털포토(서초)·㈜제논(강남)·㈜두아즈(강남)가 들어왔다. 성남·판교는 어제 7건에서 6건(키키코드㈜·티엔에이치㈜·㈜유니유니·㈜제타럭스 시스템·㈜티맥스티베로·㈜지엠디소프트)으로 시스콘·㈜날리지포인트·몽구스에이아이㈜가 빠졌다. 금천·구로는 7건(로동 2건·디자인 펀치·에스티오(STO)·㈜파워인포텍·㈜지에프씨코리아·서큘러스)으로 같고 구로 단독은 없다. 영등포는 인젠트가 내려가 ㈜데일리페이 2건만 남았고, 강동은 블루개러지 2건, 파주는 아이엔마케팅 2건이 새로 묶인다.
