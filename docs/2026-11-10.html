오늘의 채용 인사이트

점핏 3페이지는 구름·이우소프트·플래티어로 갈아탔고, 잡코리아에는 날리지포인트·당근 백엔드가 걸렸다

직전(11-09)과 비교하면 점핏 최근 등록순 3페이지에서 이비즈테크 시스템 신입(마포), 폴라리스쓰리디 관제 백엔드(구로, 최소 3년), 리보틱스 SLAM+Perception 2건(시흥), 셀키 LLM RAG(서초), 수퍼빈 로봇 SW(분당), 에스투더블유 AI Research(분당)가 빠졌다. 대신 구름 토큰허브 백엔드+뎁스팀 풀스택 2건(분당, 최소 3년), 이우소프트 AI Agent 신입+Backend Platform 2건(화성), 플래티어 AI CX(송파, 최소 3년), 일루니 AI 애플리케이션(서초, 최소 2년), 룰루랩 MLOps 주니어(강남, 최소 2년), 로아스 로봇 SW(안양, 최소 3년), 지엔에이컴퍼니 Python 백엔드(서초, 최소 2년), 엔티엘헬스케어 React/Vue·Spring 풀스택(성남, 최소 3년)이 들어왔다. 잡코리아 1페이지에서는 넥스트씨아이코리아 백엔드(과천)·북틀 프론트(마포)·티맥스티베로 프론트(성남)·지엠디소프트 AI(성남, 어제 마감)가 빠지고, 날리지포인트 JAVA 백엔드(분당, 신입·2년), 당근마켓 백엔드 산업기능요원(서초, 신입), 엘아이지아큐버 프론트(성남), 아리웍스 풀스택(인천 부평), 제이엔소프트 개발부문(안양), 제논 GenOS AI 인턴(강남), 몽구스에이아이 AI(성남)가 걸렸다. 대기업 공채는 농심(~11-09 마감)이 빠지고 한국무역정보통신·한국정보통신기술협회(TTA)가 더해져 직전 5건에서 6건이다.

백엔드는 18건에서 20건이고, Java/Spring은 8건, Node.js는 4건이다

백엔드는 직전 18건에서 20건이다. 점핏은 이비즈테크·폴라리스쓰리디 대신 구름 토큰허브(Python/AWS), 이우소프트 NestJS, 지엔에이컴퍼니 FastAPI가 들어왔다. 잡코리아는 넥스트씨아이코리아가 빠지고 날리지포인트·당근마켓 백엔드가 더해졌다. Java 또는 Spring이 칩·제목에 있는 백엔드는 8건(날리지포인트·디지타이드㈜·로동·블랙피그에이아이㈜·오픈서베이·제이디원·제타럭스 시스템·플레이웍스)으로 직전과 같다. 폴라리스쓰리디·키키코드㈜가 빠지고 날리지포인트·디지타이드가 그 자리다. Node.js는 4건(날리지포인트·리비바이오·이우소프트·티엔에이치㈜)이다. 직전 키키코드㈜·플레이웍스가 Node 칩이었던 자리는 이우소프트 NestJS와 날리지포인트(Java+Node 동시)가 채웠다. 둘 다 적힌 곳은 날리지포인트 1곳이다. 키키코드㈜는 칩이 Kotlin/Python/FastAPI로 바뀌었고, 볼타온·지엔에이컴퍼니도 FastAPI라 백엔드 Python 쪽은 3건이다.

AI 전담은 9건에서 10건이고, 웹에 AI를 붙인 자리는 10건으로 같다

AI·머신러닝 섹션은 직전 9건에서 10건이다. 점핏에서 리보틱스 2건·셀키·수퍼빈·에스투더블유가 빠지고, 플래티어 AI CX·일루니 AI 애플리케이션·룰루랩 MLOps·로아스 로봇 SW·이우소프트 AI Agent 신입이 들어왔다. 잡코리아는 지엠디소프트가 어제 마감으로 빠지고 제논 GenOS 인턴·몽구스에이아이가 더해졌으며, 디밀리언·서큘러스 Physical AI·이한크리에이티브는 그대로다. 웹 제목이나 직무에 AI가 붙은 부착형은 10건으로 같다. 엘세븐시큐리티·무월소프트·인슈넷에프씨·비오앰 AI Native 풀스택과 인프라칩 AI 관리자 2건·제이디원 AI 플랫폼 백엔드·플레이웍스 백엔드+프론트 2건·하이퍼와이즈 AI 서비스는 유지된다. 넥슨 AI본부 프론트 인턴과 서큘러스 Edge AI 인프라, 사명만 AI인 블랙피그에이아이(Spring 백엔드)는 전담·부착으로 세지 않았다.

신입 단독은 14건으로 같고, 점핏 무경력은 이우소프트 AI Agent 1건이다

경력 칸이 신입만 적힌 직무 공고는 직전과 같은 14건이다. 디지타이드·오픈서베이·티엔에이치·넥슨·당근마켓 프론트·인슈넷에프씨·서큘러스 2건·브레인즈컴퍼니·위즈돔·퍼펙토리는 그대로고, 이비즈테크가 빠진 자리에 이우소프트 AI Agent 신입·당근마켓 백엔드 신입·제논 GenOS 인턴이 들어왔다. 점핏 무경력은 직전 이비즈테크 1건에서 이우소프트 1건으로 회사만 바뀌었다. 구름 2건·다우기술 2건·엔티엘헬스케어·플래티어·로아스는 최소 3년, 일루니·룰루랩·지엔에이컴퍼니·커넥트정보는 최소 2년이라 신입 단독에는 안 잡힌다. 대기업 공채 6건은 고영·메타넷디지털·비즈테크아이·한국무역정보통신이 신입, 안랩·TTA가 신입·경력이다.

강남·서초·송파는 19건에서 24건이고, 성남·판교는 11건에서 13건이다

직무 공고 기준 강남·서초·송파는 셀키가 빠진 대신 당근마켓 백엔드(서초)·지엔에이컴퍼니(서초)·룰루랩(강남)·일루니(서초)·플래티어(송파)·제논(강남)이 들어와 직전 19건에서 24건이다. 성남·판교(분당 포함)는 수퍼빈·에스투더블유·티맥스티베로·리보틱스 자리가 빠지고 구름 2건·날리지포인트·엘아이지아큐버·엔티엘헬스케어·몽구스에이아이가 더해져 직전 11건에서 13건이다. 금천·구로는 폴라리스쓰리디(구로)가 빠져 8건에서 7건(로동 2건·서큘러스 2건·제이디원·디로그·서울소프트)이다. 과천은 넥스트씨아이코리아가 빠져 볼타온 2건·이한크리에이티브 3건, 마포는 이비즈테크·북틀이 빠져 다우기술 2건이다. 화성에 이우소프트 2건·퍼펙토리, 인천 부평에 아리웍스, 안양에 로아스·제이엔소프트가 있다.

내일 마감은 풀링포레스트 ERP와 TTA이고, 당근·너드소프트는 13일이다

내일(~11-11) 마감인 공고는 직무 풀링포레스트 ERP 풀스택(강남)과 공채 한국정보통신기술협회(TTA, 성남) 2건이다. 이어서 직무는 당근마켓 백엔드+프론트 산업기능요원 2건·너드소프트(~11-13), 다우기술 채널 서버+Web/WTS 2건(~11-17), 볼타온 백엔드+프론트 2건(~11-19), 인프라칩 2건·키키코드㈜(~11-20), 무월소프트·서큘러스 Edge AI 인프라(~11-21), 브레인즈컴퍼니 프론트 신입(~11-22) 순이다. 공채 6건은 TTA(~11-11), 비즈테크아이(~11-15), 한국무역정보통신(~11-16), 고영테크놀러지(~11-18), 안랩(~11-29), 메타넷디지털(~11-30)이다. 어제 마감이던 농심 공채와 지엠디소프트 AI는 목록에서 사라졌다.
