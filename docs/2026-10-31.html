10-30 리포트가 없어 직전 수집분(10-29)과 비교한다. 점핏 최근 등록순 3페이지에서 이지케어텍 MLOps+AI Engineer 2건(중구, 최소 2년), 위드네트웍스 보안 솔루션 신입+경력 2건(강서), 에이아이콴텍 로보어드바이저(영등포, 최소 3년), 인젠트 iBiz Java(영등포, 최소 3년), 에너자이 ML(강남, 최소 1년)이 목록 밖으로 밀려났다. 대신 베스텔라랩 백엔드·인프라 풀스택(안양, 최소 2년, Spring·React), 놀다교육연구소 백엔드+프론트 2건(구리, 최소 1년, Node.js), 블루개러지 LLM Engineer+프론트 2건(강동, 최소 3년/2년, PyTorch·React), 데이터드리븐 풀스택(관악, 최소 3년, Django·React), 수퍼빈 AI 엔지니어(성남, 최소 3년, PyTorch)가 들어왔다. 잡코리아에서는 ~10-30 마감이던 브이씨 프론트·서로티엔에스 풀스택·인포플라 풀스택이 빠졌고, 날리지포인트 JAVA(성남, 최소 2년), 리비바이오 Node 백엔드(강남), 넥스트씨아이코리아(과천), 당근마켓 프론트(서초), 대한몰 이커머스 풀스택 신입(오산), 랩투마켓 Node 풀스택(고양), 비오앰 AI Native 풀스택(강남), 서큘러스 Physical AI+Edge 인프라 2건(금천), 이한크리에이티브 VLM/LLM(과천)이 1페이지에 걸렸다. 교육생·부문별·건설 분야별 공개채용은 제외했다.

백엔드는 16건에서 20건이고, Java/Spring과 Node.js가 각 9건으로 같아졌다

백엔드는 직전 16건에서 20건이다. 점핏은 인젠트가 빠지고 놀다교육연구소가 들어와 1건으로 같고, 잡코리아는 날리지포인트·리비바이오·넥스트씨아이코리아·서큘러스 Edge 인프라가 더해져 15건에서 19건이다. Java 또는 Spring이 칩에 있는 백엔드는 9건(날리지포인트·오픈서베이·제타럭스 시스템·플레이웍스·디자인 펀치·로동·에스티오·키키코드·팀이지)으로 직전 8건에서 늘었다. Node.js(또는 NestJS·Express)는 9건(리비바이오·플레이웍스·노빌더·놀다교육연구소·에스티오·웨이온·키키코드·티엔에이치·팀이지)으로 직전 6건에서 늘었다. 둘 다 적힌 곳은 4곳(플레이웍스·에스티오·키키코드·팀이지)이다. 금천 SI(디자인 펀치·로동)와 성남 날리지포인트·제타럭스는 Java 쪽, 리비바이오·노빌더·웨이온·티엔에이치·놀다는 Node 쪽이다.

AI 전담은 9건으로 같고, 웹에 AI를 붙인 자리는 6건이다

AI·머신러닝 섹션은 직전과 같이 9건이다. 점핏 에너자이 ML과 이지케어텍 2건, 잡코리아 레피나 신입이 빠지고 블루개러지 LLM(강동, 최소 3년), 수퍼빈 AI(성남, 최소 3년), 서큘러스 Physical AI(금천 신입), 이한크리에이티브 VLM/LLM(과천)이 들어왔다. 유지분은 딥오토·제논·지엠디소프트·몽구스에이아이·에이치디씨랩스다. 웹 제목이나 직무에 AI가 붙은 부착형은 6건으로 같다. 플레이웍스 백엔드·프론트, 엘세븐시큐리티, 무월소프트, 인슈넷에프씨에 비오앰 AI Native 풀스택이 붙었고 인포플라는 마감으로 빠졌다. 넥슨 AI본부 프론트 인턴과 당근마켓 프론트는 포지션이 웹이라 부착으로 세지 않았다.

신입 단독은 14건으로 같고, 점핏 무경력은 0건이다

경력 칸이 신입만 적힌 직무 공고는 직전과 같이 14건이다. 디지타이드·오픈서베이·티엔에이치·넥슨·북틀·가온지능정보·퍼펙토리·제논·팀이지에 당근마켓, 대한몰, 인슈넷에프씨, 서큘러스 2건이 더해졌고 위드네트웍스 솔루션 신입과 레피나가 빠졌다. 점핏 무경력은 직전 위드네트웍스 1건에서 0건이다. 경력 무관을 제목에 적은 자리는 없고, 대기업 공채는 4건이다. KB캐피탈(~10-30)이 빠지고 LG CNS 자회사 비즈테크아이 하반기 신입 인턴이 들어왔으며 농심·아이센스·펜타시스템테크놀러지는 유지다.

강남·서초·송파는 18건으로 같고, 성남·판교는 7건에서 9건이다

직무 공고 기준 강남·서초·송파는 직전과 같이 18건이다. 브이씨·에너자이·인포플라가 빠지고 리비바이오·당근마켓·비오앰이 들어왔다. 성남·판교(분당 포함)는 날리지포인트 JAVA와 수퍼빈 AI가 들어와 직전 7건에서 9건이다. 금천·구로는 서큘러스 2건이 붙어 직전 8건에서 10건이다. 과천은 볼타온 2건에 넥스트씨아이코리아·이한크리에이티브가 더해져 4건이다. 영등포는 인젠트·에이아이콴텍이 빠져 인슈넷에프씨·다락트러스트·무월소프트 3건이다. 마포는 북틀 1건, 중구는 이지케어텍이 빠져 0건이다. 강동 블루개러지 2건, 구리 놀다교육연구소 2건, 관악 데이터드리븐, 안양 베스텔라랩이 있다.
