오늘의 채용 인사이트

점핏은 금융 SI·네트워크 장비로 바뀌고, 잡코리아 성남에 Java와 포렌식 AI가 돌아왔다

어제 점핏 통과 16건은 오늘 12건이다. 오투플러스 백엔드·프론트(용인), 톤28 AI 빌더 2건(성남 수정), 베스텔라랩·플라잎·씨어스테크놀로지·에스투더블유·에이오팜·브이젠·엠투피아이가 최근 등록 3페이지에서 빠졌고, 포밸류소프트 금융 SI Java 2건(관악·의왕, 최소 3년), 파이오링크 클라우드 2건(금천, 신입·1년), 서울거래 프론트 2건(영등포, 최소 3년), 에이스웍스코리아·세코어로보틱스·오픈소스컨설팅이 그 자리를 채웠다. 잡코리아에서는 리팟인터내셔널 Vision AI가 검색 첫 페이지에서 빠지고, 날리지포인트 JAVA 백엔드(성남, 최소 2년)와 아주대학교산학협력단 백엔드(수원), 지엠디소프트 포렌식 AI(성남, 최소 1년)가 다시 보인다.

백엔드 Java는 열한 건으로 벌어졌고, Node 여섯 건은 어제와 같다

백엔드 22건(어제 18)에서 Java/Spring은 11건(디자인 펀치, ㈜엠엑스엔코리아, ㈜플레이웍스, ㈜유니유니, ㈜빅링크, 엣지크로스, 포밸류소프트 2건, ㈜날리지포인트, 아주대학교산학협력단, 파이오링크 앱/클라우드)이다. Node.js는 6건(㈜엠엑스엔코리아, ㈜플레이웍스, 노빌더, 티엔에이치㈜, ㈜빅링크, ㈜리비바이오)으로 어제와 같고, 둘 다 적힌 공고는 3건(㈜엠엑스엔코리아, ㈜플레이웍스, ㈜빅링크)이다. 어제 점핏 웹 백엔드이던 오투플러스·엠투피아이 PHP 두 줄이 빠지며, 점핏 백엔드는 엣지크로스 Java·Spring과 포밸류소프트 SI Java, 파이오링크 클라우드로 바뀌었다. 차트 상위는 Java 17회, JavaScript 14회, Python 13회다.

AI 전담은 열다섯에서 여덟으로 줄었고, 웹에 AI를 붙인 다섯 건은 그대로다

AI·머신러닝 섹션은 8건(어제 15)이다. 전담에서 톤28 2건, 플라잎 2건, 씨어스테크놀로지, 에스투더블유, 에이오팜, 브이젠, 베스텔라랩, 리팟인터내셔널이 빠지고, 에이스웍스코리아 자율주행 알고리즘(강남, 최소 3년), 세코어로보틱스 SLAM(강남, 최소 3년), 지엠디소프트 포렌식 AI(성남)가 들어왔다. 유지분은 아티언스(마포)와 엣지크로스 Agentic AI(금천)다. 웹 제목에 AI가 붙은 부착형은 어제와 같은 5건(㈜플레이웍스 FE/BE, ㈜빅링크, ㈜트윔, ㈜파라미타에이아이)이다.

무경력 단독은 아홉 곳을 유지했고, 점핏 신입 창구는 금천 클라우드로 옮겨졌다

경력 칸이 신입만 적힌 직무 공고는 9건(티엔에이치㈜, ㈜큐비틱, ㈜노리앤드, ㈜크루컴퍼니, ㈜퍼펙토리, ㈜쉐이크로봇, 서큘러스, 피씨엔, 파이오링크)이다. 어제 점핏 신입이던 톤28 AI 빌더가 빠지고, 파이오링크 HCI 가상화 전문연구요원(금천, 최소 0년)이 그 창구를 이었다. 경력 무관으로 신입을 받는 자리는 ㈜인텔렉투스 백엔드(강남)만 남고, 어제 다시 붙었던 리팟인터내셔널은 오늘 목록에서 빠졌다. 주니어 컷은 포밸류소프트·엣지크로스·아티언스·서울거래·오픈소스컨설팅·에이스웍스코리아·세코어로보틱스(최소 3년), ㈜플레이웍스·㈜빅링크 백엔드(최소 3년) 쪽에 있다.

강남권과 영등포가 늘고, 성남·판교와 용인·안양은 빠졌다

직무 공고 기준 강남·서초·송파는 14건에서 17건으로 늘었다. 증분은 오픈소스컨설팅(강남), 에이스웍스코리아·세코어로보틱스(강남)다. 성남·판교는 12건에서 7건으로 줄었다. 톤28 2건과 플라잎 2건, 씨어스테크놀로지·에스투더블유·에이오팜이 빠지고 ㈜날리지포인트와 ㈜지엠디소프트가 한 줄씩 메웠다. 금천·구로는 파이오링크 2건이 더해지고 리팟인터내셔널이 빠져 9건(어제 8)이다. 영등포는 ㈜데일리페이 2건에 서울거래 프론트 2건이 붙어 4건이 됐고, 성동은 엠투피아이가 빠져 3건, 마포는 브이젠이 빠져 2건이다. 어제 용인 오투플러스·안양 베스텔라랩은 오늘 목록에 없다.

오늘 포스코와 인프라칩이 닫히고, 공채는 삼성 이탈로 다섯 건이다
