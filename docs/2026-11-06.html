직전(11-05)과 비교하면 점핏 최근 등록순 3페이지에서 만나컴퍼니 Spring Boot 백엔드(구로, 최소 2년), 네비웍스 AI 서비스 백엔드+웹앱 2건(경기, 최소 3년·1년), 비즈테크아이 클라우드 운영(마포, 최소 2년), 리보틱스 MAPF+FMS 2건(시흥, 최소 3년), 베스텔라랩 영상AI+실내내비 2건(안양, 최소 2년), WATA 비전 SLAM(분당, 최소 3년), 셀틱스테크놀로지 풀스택(용인, 최소 2년), 렉스소프트 AI/ML 신입(관악), 위볼린 개발자 신입+경력 2건(성동)이 빠졌다. 골든플래닛 AI Agent 백엔드(강남, 최소 3년)와 포스로직 이미지 프로세싱 신입(안양)만 남았다. 대신 디어유 SRE(강남, 최소 3년), 패스트파이브 네트워크 주니어(강남, 최소 1년), 스포츠투아이 웹 풀스택 신입+경력 2건(성남 분당, .NET/React), 애니캐스팅소프트웨어 주조해석 솔버 신입+경력 2건(강서), 플라잎 로봇 시스템+모바일 로봇 2건(분당, 최소 3년), 에이아이웍스 NLP/LLM 2건(송파, 최소 2년), 리브스메드 로봇 제어(성남, 최소 3년), 써큘러랩스 비전 신입+경력 2건(구리)이 들어왔다. 잡코리아 1페이지에서는 날리지포인트 JAVA 백엔드(성남), 에스티오 백엔드(금천), 당근마켓 백엔드(서초), 딜라이트홀딩스 CMS(중랑), 티맥스티베로 프론트(성남), 제논 GenOS 인턴(강남)이 빠지고, 제이디원 AI 플랫폼 백엔드(금천, 신입·1년), 플레이웍스 백엔드(강남, 신입·3년), 하이퍼와이즈 AI 서비스(서초)가 걸렸다. 교육생·부문별 공개채용은 제외했고, 대기업 공채는 어제와 같은 3건(농심·메타넷디지털·비즈테크아이)이다.

백엔드는 21건에서 17건이고, Java/Spring은 9건에서 7건, Node.js는 5건에서 4건이다

백엔드는 직전 21건에서 17건이다. 점핏은 만나컴퍼니·네비웍스 AI 백엔드·비즈테크아이 클라우드·리보틱스 FMS 대신 디어유 SRE와 패스트파이브 네트워크 주니어가 들어왔고, 골든플래닛만 유지다. 잡코리아는 날리지포인트·에스티오·당근마켓 백엔드·딜라이트홀딩스가 빠지고 제이디원과 플레이웍스 백엔드가 더해졌다. Java 또는 Spring이 칩에 있는 백엔드는 7건(로동·키키코드·디자인 펀치·제이디원·제타럭스 시스템·오픈서베이·플레이웍스)으로 직전 9건에서 만나컴퍼니·날리지포인트·에스티오가 빠지고 플레이웍스가 들어왔다. Node.js는 4건(키키코드·플레이웍스·리비바이오·티엔에이치)으로 직전 5건에서 에스티오·당근이 빠지고 플레이웍스 백엔드가 들어왔다. 둘 다 적힌 곳은 키키코드·플레이웍스 2곳이다. 금천 SI(디자인 펀치·로동·제이디원)와 성남 제타럭스·키키코드는 Java 쪽이고, 리비바이오·티엔에이치는 Node 쪽이다.

AI 전담은 13건에서 14건이고, 웹에 AI를 붙인 자리는 9건에서 11건이다

AI·머신러닝 섹션은 직전 13건에서 14건이다. 점핏에서 WATA 비전 SLAM·렉스소프트·리보틱스 MAPF·베스텔라랩 2건·위볼린 2건이 빠지고, 애니캐스팅소프트웨어 솔버 2건·플라잎 로봇 2건·에이아이웍스 NLP/LLM 2건·리브스메드 로봇 제어·써큘러랩스 비전 2건이 들어왔다. 포스로직 이미지 프로세싱 신입은 유지다. 잡코리아는 제논이 빠지고 디밀리언·서큘러스 Physical AI·이한크리에이티브·지엠디소프트 4건이 그대로다. 웹 제목이나 직무에 AI가 붙은 부착형은 9건에서 11건이다. 엘세븐시큐리티·무월소프트·인슈넷에프씨·비오앰 AI Native 풀스택과 인프라칩 AI 관리자 풀스택 2건·골든플래닛 AI Agent 백엔드는 유지고, 네비웍스 AI 백엔드가 빠진 자리에 제이디원 AI 플랫폼 백엔드·플레이웍스 백엔드+프론트 2건·하이퍼와이즈 AI 서비스가 더해졌다. 넥슨 AI본부 프론트 인턴과 서큘러스 Edge AI 인프라는 전담·부착으로 세지 않았다.

신입 단독은 17건에서 15건이고, 점핏 무경력은 애니캐스팅·스포츠투아이·써큘러랩스·포스로직 4건이다

경력 칸이 신입만 적힌 직무 공고는 직전 17건에서 15건이다. 디지타이드·오픈서베이·티엔에이치·넥슨·북틀·당근마켓 프론트·인슈넷에프씨·서큘러스 2건·브레인즈컴퍼니·위즈돔·포스로직은 그대로고, 당근마켓 백엔드·티맥스티베로·위볼린 신입·렉스소프트·제논이 빠지고 애니캐스팅소프트웨어 솔버 신입·스포츠투아이 웹 풀스택 신입·써큘러랩스 비전 신입이 들어왔다. 점핏 무경력은 포스로직·렉스소프트·위볼린 3건에서 애니캐스팅·스포츠투아이·써큘러랩스·포스로직 4건으로 바뀌었다. 골든플래닛·디어유·플라잎 2건·리브스메드는 최소 3년, 에이아이웍스 2건은 최소 2년이라 신입 단독에는 안 잡힌다. 경력 무관을 제목에 적은 자리는 없고, 대기업 공채는 3건으로 같다.

강남·서초·송파는 16건에서 20건이고, 성남·판교는 11건에서 13건이다

직무 공고 기준 강남·서초·송파는 네비웍스가 빠진 대신 디어유·패스트파이브·플레이웍스 백엔드·에이아이웍스 2건·하이퍼와이즈가 들어와 직전 16건에서 20건이다. 성남·판교(분당 포함)는 WATA가 빠지고 스포츠투아이 2건·플라잎 2건·리브스메드가 더해져 직전 11건에서 13건이다. 금천·구로는 에스티오·만나컴퍼니가 빠지고 제이디원이 들어와 9건에서 8건이다. 과천은 볼타온 2건·넥스트씨아이코리아·이한크리에이티브 4건으로 같다. 영등포는 다락트러스트·무월소프트·인슈넷에프씨 3건이다. 성동은 위볼린이 빠져 브레인즈컴퍼니 1건이다. 강서에 애니캐스팅 2건, 구리에 써큘러랩스 2건, 안양에 포스로직, 광명에 디밀리언, 하남에 인프라칩이 있다.
