백엔드는 18건에서 16건이고, Java/Spring은 8건에서 7건, Node.js는 4건으로 같다

백엔드는 직전 18건에서 16건이다. 점핏은 다우기술 채널 서버·폴라리스쓰리디·커넥트정보·이비즈테크가 빠지고 대원씨티에스 AI 인프라와 구름 토큰허브가 들어왔다. 잡코리아는 넥스트씨아이코리아가 빠지고 에스지랩(안산, Python)이 더해졌으며, 서큘러스 Edge AI 인프라(금천, 신입)는 계속 백엔드로 둔다. Java 또는 Spring이 칩에 있는 백엔드는 7건(로동·블랙피그에이아이㈜·㈜오픈서베이·㈜제이디원·㈜제타럭스 시스템·키키코드㈜·㈜플레이웍스)으로 직전 8건에서 폴라리스쓰리디가 빠졌다. Node.js는 4건(㈜리비바이오·키키코드㈜·티엔에이치㈜·㈜플레이웍스)으로 직전과 같은 4건이다. 둘 다 적힌 곳은 키키코드㈜·㈜플레이웍스 2곳이다. 금천 SI는 로동·제이디원, 성남은 제타럭스·키키코드가 Java 쪽이고, 리비바이오·티엔에이치는 Node 쪽이다. 에스지랩과 대원씨티에스·구름 토큰허브는 Python 인프라 쪽이다.

AI 전담은 9건에서 10건이고, 웹에 AI를 붙인 자리는 10건에서 8건이다

AI·머신러닝 섹션은 직전 9건에서 10건이다. 점핏에서 셀키·에스투더블유·수퍼빈·리보틱스 2건이 빠지고, 인공지능팩토리 FDE·씨어스테크놀로지 AI Developer·테이텀 AI Research·빅웨이브로보틱스 Robot SW·플래티어 AI 엔지니어·일루니 AI 애플리케이션 6건이 들어왔다. 잡코리아는 지엠디소프트가 마감으로 빠지고 제논 GenOS 인턴이 복귀했으며, 디밀리언·서큘러스 Physical AI·이한크리에이티브 3건은 그대로다. 웹 제목이나 직무에 AI가 붙은 부착형은 직전 10건에서 8건이다. 엘세븐시큐리티·무월소프트·비오앰 AI Native 풀스택과 인프라칩 AI 관리자 풀스택 2건·제이디원 AI 플랫폼 백엔드·플레이웍스 백엔드+프론트 2건은 유지되고, 인슈넷에프씨·하이퍼와이즈가 빠졌다. 블랙피그에이아이(사명에 AI, 직무는 Spring 백엔드)와 넥슨 AI본부 프론트 인턴, 서큘러스 Edge AI 인프라는 전담·부착으로 세지 않았다.

신입 단독은 14건에서 12건이고, 점핏 무경력은 0건이다

경력 칸이 신입만 적힌 직무 공고는 직전 14건에서 12건이다. 디지타이드·오픈서베이·티엔에이치·넥슨·당근마켓 프론트·서큘러스 2건·브레인즈컴퍼니·위즈돔·퍼펙토리는 그대로고, 이비즈테크 시스템 신입·티맥스티베로 프론트·북틀 프론트가 빠지고 니즈페이 풀스택 신입·제논 GenOS 인턴이 들어왔다. 점핏 무경력은 직전 이비즈테크 1건에서 0건이다. 대원씨티에스·구름 2건·인공지능팩토리·씨어스·플래티어는 최소 3년, 빅웨이브로보틱스는 최소 2년, 테이텀·일루니는 최소 1~2년이라 신입 단독에는 안 잡힌다. 대기업 공채는 6건으로 늘었다.
