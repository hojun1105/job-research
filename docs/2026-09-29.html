점핏 최근 3페이지가 통째로 바뀌고, 잡코리아에는 날리지포인트가 다시 올라왔다

어제 점핏 통과분이던 아인잡 백엔드·프론트 2건(강남, 최소 3년), 아이디에스앤트러스트 AI Agent Platform(강남, Node), 에스피코리아 백엔드(강서), 하마랩 백엔드·Vision 2건(성남), 엑소시스템즈 AI(경기), 크레셈 AI(인천 연수)가 최근 등록 3페이지에서 내려갔다. 그 자리에 영등포 에이아이콴텍 로보어드바이저 IRP 풀스택(최소 3년, Java·Spring·React), 마포 낭만아지트 백엔드(최소 3년, Java·Kotlin), 동대문 코즈코리아 소프트웨어(신입, Node·React)가 들어왔다. 잡코리아에서는 ㈜에스이파트너즈 웹시스템(중구), 모티브짐 Computer Vision 풀스택(용인), ㈜지엠디소프트 포렌식 AI(성남)가 빠지고, ㈜날리지포인트 JAVA 백엔드(분당, ~09-30)가 복귀했으며 리팟인터내셔널㈜ Vision AI(금천)·스타버스랩 AI 모델·API(고양, ~10-01)·기적기획 프론트(강남)가 신규다. 스타트업 웹·AI는 키키코드㈜·디지타이드㈜·퍼널마케팅·코즈코리아·리팟인터내셔널㈜·스타버스랩, SI는 ㈜파워인포텍·㈜지에프씨코리아·㈜위세아이텍, 금융IT 전담은 에이아이콴텍 1건, 제조 인접은 ㈜트윔이다.

백엔드 Java/Spring은 여덟 건을 유지했고, Node는 다섯 건으로 줄었다

백엔드 15건(어제 17건)에서 Java/Spring은 8건이다. ㈜마이스, 로동, 키키코드㈜, 디자인 펀치, ㈜엠엑스엔코리아, ㈜유니유니, ㈜날리지포인트, 낭만아지트가 그 칸이다. Node.js는 어제 7건에서 5건(키키코드㈜, ㈜엠엑스엔코리아, 노빌더, 티엔에이치㈜, ㈜리비바이오)으로, 아이디에스앤트러스트·에스피코리아가 빠졌다. 둘 다 적힌 공고는 2건(키키코드㈜, ㈜엠엑스엔코리아)이다. 차트 상위는 Java 15회, React 13회, Git 10회, JavaScript 10회다.

AI 전담은 세 건으로 줄었고, 웹에 AI를 붙인 자리는 다섯 건이다

AI·머신러닝 섹션은 어제 5건에서 3건이다. 하마랩 Vision·크레셈·엑소시스템즈·㈜지엠디소프트가 빠지고, 리팟인터내셔널㈜ Vision AI(금천, 경력무관)와 스타버스랩 AI 모델·API(고양)가 들어왔으며 서큘러스 Physical AI는 유지다. 웹 제목이나 직무에 AI가 붙은 부착형은 어제 8건에서 5건이다. ㈜트윔 백엔드, ㈜세인티 프론트, ㈜파라미타에이아이·㈜인포플라·몽구스에이아이㈜ 풀스택이고, 하마랩 백엔드·아이디에스앤트러스트·모티브짐이 빠졌다.

신입 단독은 여덟 건으로 늘었고, 경력 무관은 인텔렉투스와 리팟이다

경력 칸이 신입만 적힌 직무 공고는 어제 7건에서 8건이다. ㈜마이스, 디지타이드㈜, 티엔에이치㈜, ㈜큐비틱, ㈜투모어스텝스, ㈜퍼펙토리, 서큘러스에 점핏 코즈코리아(동대문)가 더해졌다. 신입을 경력 무관으로 받는 자리는 ㈜인텔렉투스 백엔드(강남)와 리팟인터내셔널㈜ Vision AI(금천)다. 어제 크레셈(인천 연수, 최소 3년·신입 무관)은 목록에서 빠졌다.

강남·서초·송파는 14건이고, 성남에는 날리지포인트가 다시 들어왔다

직무 공고 기준 강남·서초·송파는 어제 16건에서 14건이다. 아인잡 2건·아이디에스앤트러스트가 빠지고 기적기획 프론트(강남)가 들어왔다. 성남·판교는 어제 8건에서 6건으로, 하마랩 2건·㈜지엠디소프트 대신 ㈜날리지포인트가 복귀했고 유지분은 키키코드㈜·티엔에이치㈜·㈜유니유니·㈜제타럭스 시스템·몽구스에이아이㈜다. 금천·구로는 어제 7건에서 8건(로동 2건·디자인 펀치·에스티오(STO)·㈜파워인포텍·㈜지에프씨코리아·서큘러스·리팟인터내셔널㈜)이고 구로 단독은 없다. 중구는 ㈜에스이파트너즈가 빠지고 ㈜취팡 1건, 성동은 ㈜엠엑스엔코리아 1건이다. 동대문 코즈코리아·마포 낭만아지트·영등포 에이아이콴텍이 새로 보이고 과천 ㈜위세아이텍·남양주 퍼널마케팅·종로 디지타이드㈜·고양 스타버스랩은 남았다.
