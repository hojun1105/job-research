백엔드는 22건에서 23건이고, Java/Spring은 8건, Node.js는 4건이다

백엔드는 점핏 스포카·윗유·텐빌리언·쿤텍과 잡코리아 ㈜제타럭스 시스템이 빠지고, 혜성테크윈 2건·커넥트정보 2건·다우기술 인프라·코그니텀㈜가 들어와 직전 22건에서 23건이다. Java 또는 Spring이 칩에 있는 백엔드는 8건(㈜날리지포인트·㈜에이블짐정보·㈜오픈서베이·㈜제이디원·㈜플레이웍스·디지타이드㈜·로동·블랙피그에이아이㈜)이다. Node.js는 4건(㈜리비바이오·㈜스테이지파이브·티엔에이치㈜·㈜날리지포인트)으로 직전과 같고, 날리지포인트만 Java+Node를 같이 적었다. 키키코드㈜·코그니텀㈜·㈜볼타온은 FastAPI/Python, 에스지랩㈜는 Python, 씨너지파트너㈜는 .NET이다.

AI 전담은 6건에서 11건이고, 웹에 AI를 붙인 자리는 11건이다

AI·머신러닝 섹션은 직전 6건에서 11건이다. 피아스페이스·플라잎·㈜스피링크가 빠지고, 뷰런테크놀로지 2건·모아이스·뉴로다임·엔티엘헬스케어·다우기술 AI·㈜유토·㈜팜소프트가 들어왔다. 서큘러스 Physical AI·이한크리에이티브㈜·㈜화신이앤엘 3건은 남았다. 웹 직무에 AI를 붙인 부착형은 11건이다. 윗유가 점핏에서 나가 부착은 12건에서 줄었고, 코그니텀㈜ AI Native 백엔드가 그 자리를 일부 채웠다. 블랙피그에이아이(사명만 AI)·㈜넥슨 AI본부 프론트 인턴·서큘러스 Edge AI 인프라는 전담·부착 어디에도 넣지 않았다.

신입 단독은 11건이고, 점핏 무경력은 혜성테크윈·커넥트정보 2건이다

경력 칸이 신입만 적힌 직무 공고는 11건이다. 잡코리아는 디지타이드·오픈서베이·티엔에이치·넥슨·서큘러스 2건·브레인즈컴퍼니·인슈넷에프씨·퍼펙토리 9건이고, 점핏 무경력은 혜성테크윈 네트워크 신입·커넥트정보 네트워크 신입 2건이다. 어제 목록의 아이포트폴리오 웹 신입이 빠지고 혜성테크윈·커넥트정보가 더해져 10건에서 11건이다. 뷰런 Edge AI는 최소 1년, 모아이스·뉴로다임은 최소 2년, 다우 AI·아이알큐더스는 최소 1~3년이라 이 명단에는 넣지 않았다. 대기업 공채 6건은 신입 공고로 따로 둔다.

강남·서초·송파는 20건에서 18건이고, 금천·구로는 11건에서 9건이다

직무 공고 기준 강남·서초·송파는 스포카·윗유·피아스페이스·지피에이코리아가 빠지고 뷰런테크놀로지 서초 2건이 붙어 직전 20건에서 18건이다. 금천·구로는 텐빌리언 구로 2건이 나가 로동 2건·제이디원·디로그·서큘러스 2건·서울소프트·젠티·화신이앤엘 9건이다. 성남·판교(분당·수정 포함)는 쿤텍·플라잎이 빠지고 다우기술 2건·에이치씨엔씨·엔티엘헬스케어가 들어와 10건이다. 영등포는 아이알큐더스가 더해져 무월소프트·인슈넷에프씨·다락트러스트·아이알큐더스 4건이고, 과천 4건(볼타온 2·넥스트씨아이코리아·이한크리에이티브)은 같다. 강서는 아이포트폴리오 대신 커넥트정보 2건·코그니텀·유토 4건, 성동은 브레인즈+뉴로다임, 동작은 모아이스다.

오늘 마감은 볼타온·삼성메디슨·앰코·커넥트정보 신입이고, 내일은 로동·인프라칩·키키코드다

오늘(~11-19) 마감인 공고는 직무 ㈜볼타온 백엔드+프론트 2건·커넥트정보 네트워크 신입, 공채 삼성메디슨·앰코테크놀로지코리아로 총 5건이다. 어제 마감이던 ㈜고영테크놀러지 공채는 목록에서 빠졌다. 이어서 로동 백엔드+프론트 2건·㈜인프라칩 2건·키키코드㈜(~11-20), 무월소프트·서큘러스 Edge AI 인프라(~11-21), 브레인즈컴퍼니 프론트 신입·㈜화신이앤엘·디지타이드㈜(~11-22), 엘아이지아큐버 프론트(~11-23) 순이다. 공채 6건은 삼성메디슨·앰코(~11-19), 안랩·엘에스아이티씨(~11-29), 메타넷디지털·㈜슈프리마 인턴십(~11-30)이다.
