오늘의 채용 인사이트

점핏 3페이지가 바뀌었고, 잡코리아에서는 에스티오와 퍼펙토리가 빠졌다

직전(11-03)과 비교하면 점핏 최근 등록순 3페이지에서 청림인베스트 Java/Spring 백엔드(연수, 최소 3년), 씨메스 Python 백엔드+프론트 2건(강남, 최소 3년), 우주에이엠에프 풀스택(수원, 최소 2년), 베스텔라랩 자율주행(안양, 최소 3년), 에이인비 AI(과천, 최소 1년), 엔티엘헬스케어 MLOps(성남, 최소 1년), 크레셈 Vision SW(연수, 최소 2년)가 빠졌다. 26도라인 서버+JAVA 풀스택 2건(경기 광주, 최소 1년), 이비즈테크 클라우드 신입(마포), 크레셈 알고리즘(연수, 최소 3년)은 그대로다. 대신 만나컴퍼니 Spring Boot 백엔드(구로, 최소 2년), 코보시스 서버(송파, 최소 3년), 베스텔라랩 영상AI+실내내비 2건(안양, 최소 2년), 리보틱스 MAPF+FMS 2건(시흥, 최소 3년), 쓰리아이 SLAM+컴퓨터비전 인턴 2건(강남, 최소 3년·신입)이 들어왔다. 잡코리아 1페이지에서는 에스티오 백엔드(금천), 랩투마켓 로봇 풀스택(고양), 퍼펙토리 풀스택(화성, ~11-03 마감)이 없었고, 인프라칩 AI 관리자 풀스택 2건(하남·성남, 최소 1년)이 새로 걸리고 제논 GenOS AI 인턴(강남)이 복귀했다. 교육생·부문별 공개채용은 제외했고, 대기업 공채는 아이센스(~11-11)가 검색 1페이지에서 빠져 3건(농심·메타넷디지털·비즈테크아이)이다.

백엔드는 20건으로 같고, Java/Spring은 9건, Node.js는 5건에서 4건이다

백엔드는 직전과 같은 20건이다. 점핏은 청림인베스트·씨메스 대신 만나컴퍼니·코보시스·리보틱스 FMS 3건이고, 26도라인 서버와 이비즈테크는 유지다. Java 또는 Spring이 칩에 있는 백엔드는 9건(만나컴퍼니·코보시스·로동·키키코드·디자인 펀치·날리지포인트·오픈서베이·제타럭스 시스템·당근마켓)으로 직전 9건과 같다. 청림인베스트·에스티오가 빠지고 만나컴퍼니·코보시스가 들어왔다. Node.js(또는 NestJS)는 4건(키키코드·리비바이오·티엔에이치·당근마켓)으로 직전 5건에서 에스티오가 빠졌다. 둘 다 적힌 곳은 2곳(키키코드·당근마켓)이다. 금천 SI(디자인 펀치·로동)와 성남 날리지포인트·제타럭스, 구로 만나컴퍼니·송파 코보시스는 Java 쪽이고, 리비바이오·티엔에이치는 Node 쪽이다.

AI 전담은 9건에서 11건이고, 웹에 AI를 붙인 자리는 4건에서 6건이다

AI·머신러닝 섹션은 직전 9건에서 11건이다. 점핏에서 크레셈 Vision SW·베스텔라랩 자율주행·에이인비·엔티엘헬스케어가 빠지고, 베스텔라랩 영상AI+실내내비 2건·리보틱스 MAPF·쓰리아이 SLAM+비전 인턴 2건이 들어왔다. 잡코리아는 제논이 복귀해 디밀리언·서큘러스 Physical AI·이한크리에이티브·지엠디소프트와 함께 5건이다. 웹 제목이나 직무에 AI가 붙은 부착형은 4건에서 6건이다. 엘세븐시큐리티·무월소프트·인슈넷에프씨·비오앰 AI Native 풀스택이 유지고, 인프라칩 AI 관리자 풀스택 2건이 더해졌다. 넥슨 AI본부 프론트 인턴과 서큘러스 Edge AI 인프라는 전담·부착으로 세지 않았다.

신입 단독은 14건에서 15건이고, 점핏 무경력은 이비즈테크와 쓰리아이 인턴 2건이다

경력 칸이 신입만 적힌 직무 공고는 직전 14건에서 15건이다. 디지타이드·오픈서베이·티엔에이치·넥슨·북틀·당근마켓 백엔드·프론트·인슈넷에프씨·서큘러스 2건·티맥스티베로·이비즈테크·위즈돔은 그대로고, 퍼펙토리가 마감으로 빠지고 쓰리아이 컴퓨터비전 인턴과 제논 전환형 인턴이 들어왔다. 점핏 무경력은 이비즈테크에 쓰리아이 인턴이 더해져 2건이다. 리보틱스·코보시스·크레셈 알고리즘·쓰리아이 SLAM은 최소 3년, 만나컴퍼니는 최소 2년이라 신입 단독에는 안 잡힌다. 경력 무관을 제목에 적은 자리는 없고, 대기업 공채는 4건에서 3건이다.

강남·서초·송파는 15건에서 17건이고, 성남·판교는 10건으로 같다

직무 공고 기준 강남·서초·송파는 코보시스 송파·쓰리아이 강남 2건·제논 강남이 들어오고 씨메스 강남 2건이 빠져 직전 15건에서 17건이다. 성남·판교(분당 포함)는 엔티엘헬스케어가 빠지고 인프라칩 성남이 더해져 직전과 같은 10건이다. 금천·구로는 에스티오가 빠지고 만나컴퍼니 구로가 들어와 8건으로 같다. 과천은 에이인비가 빠져 볼타온 2건·넥스트씨아이코리아·이한크리에이티브 4건이다. 영등포는 다락트러스트·무월소프트·인슈넷에프씨 3건이다. 경기 시흥에 리보틱스 2건, 안양에 베스텔라랩 2건, 광주 26도라인 2건, 하남 인프라칩, 광명 디밀리언이 있다.

오늘 마감은 리보틱스 FMS고, 공채는 농심이 가장 가깝다

가장 가까운 마감은 오늘(~11-04) 리보틱스 FMS 시스템이다. 이어서 직무는 지엠디소프트 AI(~11-09), 풀링포레스트 ERP(~11-11), 딜라이트홀딩스 CMS·당근마켓 백엔드·프론트·너드소프트(~11-13), 인프라칩 2건·키키코드(~11-20), 서큘러스 Edge AI 인프라(~11-21) 순이다. 공채는 아이센스가 검색 1페이지에서 빠졌고, 남은 3건 중 농심(~11-09), 비즈테크아이(~11-15), 메타넷디지털(~11-30) 순이다. 어제 오늘 마감이던 퍼펙토리는 목록에서 사라졌다.
