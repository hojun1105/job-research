점핏은 구로 웹·강남 AI로 갈아끼워졌고, 잡코리아는 성남 Java와 고양 AI가 돌아왔다

어제 점핏 통과 9건은 숫자만 같고 구성이 거의 갈렸다. 뮤즈라이브 Spring(마포), 에너닷 프론트(강남), 한국이에스지데이터 풀스택(중구), 소프트넷 Azure(강남), 엣지크로스 AIoT·Agentic 2건(금천)이 최근 등록 3페이지에서 빠지고, 텐빌리언 백엔드·프론트 2건(구로, 최소 2년), 에너자이 AI 컴파일러 신입·ML 2건(강남), 메디웨일 AI-SaMD(강남, 최소 1년), (주)낭만아지트 백엔드(마포, 최소 3년), 뉴로다임 AI(성동, 최소 2년), 티엔에이치 경력 Node(분당, 최소 3년)가 들어왔다. 웨이센 프론트 신입(강남)만 유지다. 잡코리아에서는 ㈜날리지포인트 JAVA(성남)와 스타버스랩(고양)이 재진입했고, ㈜드림위드컴퍼니 풀스택(강북), ㈜세인티 프론트(강서), ㈜인포플라·㈜비자림이 신규다. 어제 보이던 ㈜에이블짐정보는 첫 페이지에서 빠졌다.

백엔드 Java는 일곱 건, Node는 다섯 건으로 둘 다 한 건씩 늘었다

백엔드 18건(어제 17)에서 Java/Spring은 7건(디자인 펀치, ㈜엠엑스엔코리아, ㈜유니유니, ㈜날리지포인트, 아주대학교산학협력단, 텐빌리언, (주)낭만아지트)이다. 어제 6건이던 자리는 뮤즈라이브가 빠지고 텐빌리언 Spring Boot(구로)·낭만아지트 Java(마포)·날리지포인트가 들어오며 늘었다. Node.js는 5건(㈜엠엑스엔코리아, ㈜리비바이오, 노빌더, 티엔에이치㈜ 신입, 티엔에이치 점핏 경력)으로 어제 4건보다 한 건 많다. 둘 다 적힌 공고는 ㈜엠엑스엔코리아 1건으로 같다. 점핏 웹 백엔드는 텐빌리언·낭만아지트·티엔에이치 경력 세 줄이다. 차트 상위는 React 11회, JavaScript 10회, Java 9회다.

AI 전담은 일곱에서 열 건이 됐고, 웹에 AI를 붙인 네 건이 남았다

AI·머신러닝 섹션은 10건(어제 7)이다. 전담에서 엣지크로스 Agentic이 빠지고, 에너자이 2건(강남 컴파일러 신입·ML), 메디웨일(강남), 뉴로다임(성동), ㈜비자림 ERP MES AI(강동, 경력 무관), 스타버스랩(고양)이 들어왔다. 유지분은 서큘러스·㈜지엠디소프트·㈜제논·피씨엔이다. 웹 제목에 AI가 붙은 부착형은 4건(㈜트윔 백엔드, ㈜파라미타에이아이 풀스택, ㈜세인티 프론트, ㈜인포플라 AI Agent 풀스택)이다. 어제 부착 3건이던 엣지크로스 AIoT는 점핏에서 빠졌다.

무경력 단독은 아홉 건으로 줄었고, 점핏 신입 창구는 강남 AI·프론트로 남았다

경력 칸이 신입만 적힌 직무 공고는 9건이다. 어제 11건에서 (주)코즈코리아·㈜쉐이크로봇이 빠지고, 에너자이 AI 컴파일러 신입(강남)이 더해졌다. 유지분은 웨이센, 티엔에이치㈜, ㈜큐비틱, ㈜크루컴퍼니, ㈜퍼펙토리, 서큘러스, ㈜제논, 피씨엔이다. 경력 무관으로 신입을 받는 자리는 ㈜인텔렉투스 백엔드(강남)에 ㈜비자림(강동)이 붙었다. 주니어 컷은 (주)낭만아지트·티엔에이치 점핏 경력·㈜드림위드컴퍼니(최소 3년), 텐빌리언(최소 2년) 쪽에 있다.

성남·판교가 다섯에서 일곱으로 늘고, 강남권은 열다섯 건이다

직무 공고 기준 강남·서초·송파는 어제 16건에서 15건이다. 에너닷·소프트넷이 빠지고 에너자이 2건과 메디웨일이 강남을 채웠다. 성남·판교는 5건에서 7건으로 늘었다. ㈜날리지포인트와 티엔에이치 점핏 경력이 더해지고, 지엠디소프트·유니유니·제타럭스·몽구스에이아이㈜·티엔에이치㈜가 남았다. 금천·구로는 엣지크로스 2건이 빠지고 텐빌리언 2건이 들어와 6건(어제 7)이다. 성동은 뉴로다임이 더해져 4건, 마포는 뮤즈라이브 대신 낭만아지트가 붙어 2건, 중구는 한국이에스지데이터가 빠져 2건이다.
