스타트업은 비전·Physical AI를, SI는 풀스택 신입을, 대기업은 인턴 공채를 뽑는다

직전(11-19, 총 67건)과 비교하면 오늘은 직무 53건+공채 4건으로 총 57건이다. 점핏 3페이지가 통째로 바뀌어 혜성테크윈 네트워크 2건·커넥트정보 경력·다우기술 2건·뷰런테크놀로지 2건·모아이스·뉴로다임·엔티엘헬스케어·아이알큐더스가 나가고, 플라잎 Physical AI(분당 min1)·폴라리스쓰리디 관제 백엔드(구로 min3)·에이아이웍스 비전 2건(송파)·이노비즈 반도체비전 2건(시흥)이 들어왔다. 잡코리아에서는 마감된 ㈜볼타온 2건과 ㈜에이블짐정보 백엔드·㈜에이치씨엔씨·㈜인슈넷에프씨·㈜팜소프트 AI Agent가 빠지고, ㈜다담리테일(유맥ITC) 풀스택 신입·㈜제논 GenOS 인턴이 들어왔으며 에이블짐은 JAVA/JSP 프론트·백엔드 공고로 풀스택에 다시 붙었다. 스타트업 AI는 플라잎·에이아이웍스 2건·㈜제논·㈜유토·이노비즈 2건이고, SI는 다담리테일·폴라리스쓰리디·㈜서울소프트·㈜제이엔소프트다. 금융IT는 ㈜날리지포인트 JAVA 백엔드 1건이 유지됐다. 대기업은 ㈜넥슨 AI본부 프론트 인턴과 공채 4건(삼성메디슨·앰코 마감)이다.

백엔드는 23건에서 18건이고, Java/Spring은 8건, Node.js는 4건이다

백엔드는 점핏 혜성테크윈 2건·다우기술 인프라·커넥트정보 경력과 잡코리아 ㈜볼타온·㈜에이블짐정보 백엔드가 빠지고, 폴라리스쓰리디 관제 백엔드가 들어와 직전 23건에서 18건이다. Java 또는 Spring이 칩에 있는 백엔드는 8건(㈜날리지포인트·㈜오픈서베이·㈜제이디원·㈜플레이웍스·디지타이드㈜·로동·블랙피그에이아이㈜·폴라리스쓰리디)으로 직전과 같다. 에이블짐 JAVA 백엔드가 빠지고 폴라리스쓰리디 Spring Boot가 그 자리를 채웠다. Node.js는 4건(㈜리비바이오·㈜스테이지파이브·티엔에이치㈜·㈜날리지포인트)으로 같고, 날리지포인트만 Java+Node를 같이 적었다. 키키코드㈜·코그니텀㈜는 FastAPI/Python, 에스지랩㈜는 Python, 씨너지파트너㈜는 .NET이다.

AI 전담은 11건에서 10건이고, 웹에 AI를 붙인 자리는 10건이다

AI·머신러닝 섹션은 직전 11건에서 10건이다. 뷰런테크놀로지 2건·모아이스·뉴로다임·엔티엘헬스케어·다우기술 AI·㈜팜소프트가 빠지고, 플라잎·에이아이웍스 2건·이노비즈 2건·㈜제논이 들어왔다. 서큘러스 Physical AI·이한크리에이티브㈜·㈜화신이앤엘·㈜유토 4건은 남았다. 웹 직무에 AI를 붙인 부착형은 10건이다. ㈜인슈넷에프씨가 나가 부착은 11건에서 줄었고, 코그니텀㈜·㈜제이디원·㈜플레이웍스 2건·㈜엘세븐시큐리티 2건·무월소프트·㈜비오앰·㈜인프라칩 2건이 유지됐다. 블랙피그에이아이(사명만 AI)·㈜넥슨 AI본부 프론트 인턴·서큘러스 Edge AI 인프라는 전담·부착 어디에도 넣지 않았다.

신입 단독은 11건이고, 점핏 무경력은 커넥트정보 1건이다

경력 칸이 신입만 적힌 직무 공고는 11건이다. 잡코리아는 디지타이드·오픈서베이·티엔에이치·넥슨·서큘러스 2건·브레인즈컴퍼니·퍼펙토리·제논·다담리테일 10건이고, 점핏 무경력은 커넥트정보 네트워크 신입 1건이다. 어제 목록의 혜성테크윈 네트워크 신입·인슈넷에프씨가 빠지고 제논 인턴·다담리테일 신입이 더해져 11건을 유지했다. 플라잎·에이아이웍스 로봇은 최소 1년, 이노비즈는 최소 1~3년이라 이 명단에는 넣지 않았다. 대기업 공채 4건은 신입 공고로 따로 둔다.

강남·서초·송파는 18건에서 20건이고, 금천·구로는 9건에서 10건이다

직무 공고 기준 강남·서초·송파는 뷰런테크놀로지 서초 2건이 빠지고 에이아이웍스 송파 2건·㈜다담리테일 송파·㈜제논 강남이 붙어 20건이다. 금천·구로는 폴라리스쓰리디 구로가 더해져 로동 2건·제이디원·디로그·서큘러스 2건·서울소프트·젠티·화신이앤엘·폴라리스쓰리디 10건이다. 성남·판교(분당 포함)는 다우기술 2건·에이치씨엔씨·엔티엘헬스케어가 빠지고 플라잎 분당이 들어와 날리지포인트·키키코드·티엔에이치·넥슨·엘아이지아큐버·인프라칩 성남·플라잎 7건이다. 영등포는 인슈넷에프씨·아이알큐더스가 나가 무월소프트·다락트러스트 2건이고, 과천은 볼타온 2건이 마감되어 넥스트씨아이코리아·이한크리에이티브 2건이다. 강서는 커넥트정보 신입·코그니텀·유토 3건, 성동은 브레인즈만, 시흥은 이노비즈 2건이다.

오늘 마감은 로동·인프라칩·키키코드이고, 내일은 무월소프트·서큘러스 Edge다

오늘(~11-20) 마감인 공고는 로동 백엔드+프론트 2건·㈜인프라칩 풀스택 2건·키키코드㈜ 백엔드로 총 5건이다. 어제 마감이던 ㈜볼타온 2건·삼성메디슨·앰코테크놀로지코리아·커넥트정보 구 신입 공고는 목록에서 빠졌다. 이어서 무월소프트·서큘러스 Edge AI 인프라(~11-21), 브레인즈컴퍼니 프론트 신입·㈜화신이앤엘·디지타이드㈜(~11-22), 엘아이지아큐버 프론트(~11-23) 순이다. 공채 4건은 안랩·엘에스아이티씨(~11-29), 메타넷디지털·㈜슈프리마 인턴십(~11-30)이다.
