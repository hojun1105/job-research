오늘의 채용 인사이트

점핏에서 블루개러지 LLM이 빠졌고, 잡코리아에는 F&F와 나이스디앤알이 들어왔다

직전(11-01)과 비교하면 점핏 최근 등록순 3페이지에서 블루개러지 LLM 엔지니어(강동, 최소 3년)가 빠졌다. 베스텔라랩 풀스택(안양, 최소 2년), 놀다교육연구소 백엔드+프론트 2건(구리, 최소 1년), 제네시스네스트 Java 백엔드+프론트 2건(용인, 최소 1년), 콴텍 로보어드바이저 풀스택(영등포, 최소 3년)은 그대로다. 잡코리아에서는 노빌더 백엔드+프론트 2건(서초, Node/NestJS·React)과 딥오토 AI 엔지니어(강남)가 1페이지에 없었고, F&F 디지털본부 Java/Spring 백엔드(강남, 신입·경력, ~11-15)와 나이스디앤알 웹 풀스택(서대문, 신입·경력, ~11-13)이 새로 걸렸다. 교육생·부문별 공개채용은 제외했고, 대기업 공채 5건(농심·메타넷디지털·비즈테크아이·아이센스·펜타시스템테크놀러지)은 유지다.

백엔드는 19건으로 같고, Java/Spring은 9건에서 10건, Node.js는 8건에서 7건이다

백엔드는 직전 19건과 같다. 점핏은 놀다교육연구소·제네시스네스트 2건으로 같고, 잡코리아는 노빌더가 빠지고 F&F가 들어와 17건으로 같다. Java 또는 Spring이 칩에 있는 백엔드는 10건(F&F·오픈서베이·제타럭스 시스템·디자인 펀치·로동·에스티오·키키코드·팀이지·제네시스네스트·당근마켓)으로 직전 9건에서 늘었다. Node.js(또는 NestJS)는 7건(리비바이오·놀다교육연구소·에스티오·키키코드·티엔에이치·팀이지·당근마켓)으로 직전 8건에서 줄었다. 둘 다 적힌 곳은 4곳(에스티오·키키코드·팀이지·당근마켓)으로 같다. 금천 SI(디자인 펀치·로동)와 용인 제네시스네스트·성남 제타럭스·강남 F&F는 Java 쪽, 리비바이오·티엔에이치·놀다는 Node 쪽이다.

AI 전담은 8건에서 6건이고, 웹에 AI를 붙인 자리는 4건으로 같다

AI·머신러닝 섹션은 직전 8건에서 6건이다. 점핏 블루개러지 LLM과 잡코리아 딥오토가 빠지고 몽구스에이아이·서큘러스 Physical AI·에이치디씨랩스·이한크리에이티브·제논·지엠디소프트가 남았다. 웹 제목이나 직무에 AI가 붙은 부착형은 4건으로 같다. 엘세븐시큐리티·무월소프트·인슈넷에프씨·비오앰 AI Native 풀스택이 유지다. 넥슨 AI본부 프론트 인턴과 서큘러스 Edge AI 인프라는 전담·부착으로 세지 않았다.

신입 단독은 16건으로 같고, 점핏 무경력은 0건이다

경력 칸이 신입만 적힌 직무 공고는 직전 16건과 같다. 디지타이드·오픈서베이·티엔에이치·넥슨·북틀·가온지능정보·퍼펙토리·제논·팀이지·당근마켓 백엔드·프론트·대한몰·인슈넷에프씨·서큘러스 2건·티맥스티베로가 그대로다. 새로 들어온 F&F와 나이스디앤알은 신입·경력이라 신입 단독에는 안 잡힌다. 점핏은 놀다·제네시스네스트가 최소 1년, 베스텔라랩이 최소 2년, 콴텍이 최소 3년이라 무경력은 0건으로 같다. 경력 무관을 제목에 적은 자리는 없고, 대기업 공채는 5건으로 같다.

강남·서초·송파는 17건에서 15건이고, 성남·판교와 금천·구로는 같다

직무 공고 기준 강남·서초·송파는 노빌더 서초 2건과 딥오토 강남이 빠지고 F&F 강남이 들어와 직전 17건에서 15건이다. 성남·판교(분당 포함)는 8건, 금천·구로는 9건으로 같다. 과천은 볼타온 2건·넥스트씨아이코리아·이한크리에이티브 4건으로 같다. 영등포는 콴텍·인슈넷에프씨·다락트러스트·무월소프트 4건으로 같다. 강동은 블루개러지가 빠져 0건이고, 서대문에 나이스디앤알이 생겼다. 용인 제네시스네스트 2건, 구리 놀다교육연구소 2건, 안양 베스텔라랩은 유지다.

오늘 마감은 펜타시스템 40기고, 내일 퍼펙토리가 있다

가장 가까운 마감은 오늘(~11-02) 펜타시스템테크놀러지 40기 신입 공채다. 이어서 퍼펙토리 풀스택(~11-03)이다. 직무는 지엠디소프트 AI(~11-09), 풀링포레스트 ERP(~11-11), 딜라이트홀딩스 CMS·당근마켓 백엔드·프론트·너드소프트·나이스디앤알(~11-13), 가온지능정보(~11-14), F&F 백엔드·에이치디씨랩스(~11-15) 순이다. 공채는 펜타시스템테크놀러지 다음이 농심(~11-09), 아이센스(~11-11), 비즈테크아이(~11-15), 메타넷디지털(~11-30)이다.
